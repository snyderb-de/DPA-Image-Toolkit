User Manual

Use this guide for the EXE release of DPA Image Toolkit. Outputs are written into tool-specific folders next to the selected input; source files are not moved, overwritten, or deleted.

Release Contract

Inputs Stay Put

Every tool follows the same safety rule: copy outputs, never move inputs.

EXE Path

The supported deployment is the PyInstaller Windows one-file EXE.

Error Review

When a job logs failures, use View Errors to open the run's error folder.

Auto Crop

Detects meaningful content in an image folder and writes cropped copies into cropped/.

  • Input: folder of TIFF, JPEG, PNG, BMP, or GIF images.
  • Option: Straighten before crop runs deskew before crop detection.
  • Skipped blank or tiny-content pages are reported in the activity log.

Straighten Images Beta (in Testing)

Deskews already-cropped or full-page image sets without cropping the canvas.

  • Input: folder of supported image files.
  • Output: straightened/.
  • Pixel dimensions are preserved; DPI metadata is kept when available.

Merge TIFFs

Merge TIFFs groups page files by filename. The required pattern is: 

{% raw %}{name}_{group}_{sequence}.tif
{name}_{group}_{sequence}.tiff{% endraw %}
  • The final sequence must be an underscore plus a positive integer: _1, _01, _001, _0001, _1000.
  • The merge group name is everything before the trailing sequence.
  • Example: 9200-T16-000_207_003.tif belongs to group 9200-T16-000_207.
  • Files in a group are sorted by numeric value, so _10 comes after _9 regardless of padding.
  • A one-file group is valid. Invalidly named TIFFs are skipped with a warning.

Split Multi-Page TIFFs

Extracts pages from multi-page TIFF files into single-page TIFF outputs.

  • File mode output: sibling <name>_pages/ folders.
  • Folder mode output: extracted-pages/.
  • Single-page TIFFs are skipped.

Add Border

Adds a white border to each image copy and writes results into bordered/.

  • Border size is 2.5% of image dimensions, clamped between 15 and 100 pixels.
  • Original image files stay in the selected folder.

OCR to PDF

Groups page images into searchable PDFs using OCR tooling on the local machine.

  • Input: folder of page image files.
  • Output: PDFs/<group_name>.pdf.
  • Files ending in _0001, _0002, and so on are grouped into one document.
  • Quality-flagged pages can stay in the PDF without OCR text when the quality check is enabled.

PDF Conversion

Runs PDF-focused copy-out workflows.

  • Reduce Size: one PDF or a folder of PDFs to reduced-pdfs/.
  • Split PDF: one PDF to page PDFs or page images.
  • Extract Pages: selected pages to extracted-pages/; optional remaining-pages copy leaves the source unchanged.
  • PDF/A: preview conversion mode for archival PDF/A output.

Updates

Checks an admin-managed bundled EXE without contacting GitHub.

  • Default source: X:\Apps\DPA-Image-Toolkit.exe.
  • Update source: folder path or direct path to DPA-Image-Toolkit.exe.
  • Version signal: Windows EXE ProductVersion or FileVersion metadata.
  • Current behavior: stages a newer EXE locally, verifies its SHA-256, and prompts for restart.

Troubleshooting

  • If Start is disabled, select a valid input folder or file first.
  • If a dependency warning appears, install the missing dependency on the Windows machine or contact support.
  • If a job has failures, click View Errors and review the activity log before retrying.
