User Manual

DPA Image Toolkit

Windows EXE toolkit for archival image cleanup and TIFF workflow management. Seven integrated tools cover the full scan-to-archive pipeline: crop, straighten, merge, split, border, OCR, and PDF conversion.

First Steps

Getting Started

Launching the App

On Windows, download and double-click DPA Image Toolkit.exe. The release is a single EXE with no required _internal/ folder. The EXE opens the toolkit in a native web-window and does not require a local Python install.

On macOS or Linux, run python launch_web.py from the project folder after installing dependencies.

Installing Dependencies

Run pip install -r requirements.txt from the project folder. Core requirements are Pillow, opencv-python, numpy, pypdf, pypdfium2, flask, and pywebview.

The OCR to PDF tool additionally requires Tesseract OCR installed locally with the English language pack (eng). All other tools work without it.

General Behavior

Every tool writes output to a subfolder alongside your source — originals are never overwritten. A live log shows what the tool is doing file by file. If any files fail, an error report button appears after the run so you can review what went wrong.

Click New Job after a run completes to reset the panel and start fresh without relaunching the app.

Tool 1 of 7

Auto Crop

Detects non-white content in scanned images and crops away scanner-created white space. All meaningful regions are collected into a single bounding box before the crop is applied — so nothing is lost to an overly tight cut. Original files are untouched; cropped copies go to a subfolder. Enable Straighten before crop when scans are visibly skewed.

Input

A folder of image files. Supported: TIFF, JPEG, PNG, BMP, GIF.

Output

  • input_folder/cropped/ — successfully cropped images
  • input_folder/errored-files/ — files that failed

How to Use

  1. Select the image folder using the folder picker button.
  2. The stats strip shows how many supported image files were found.
  3. Optionally enable Straighten before crop.
  4. Click Start. The live log shows each file as it processes.
  5. When complete, open cropped/ to review output.
  6. If any files failed, click Error Report to review them.

Notes

  • Works best on scans with white or near-white backgrounds (brightness 254+).
  • Content threshold is 253 — pixels at or below this value are treated as content.
  • Contours smaller than 50×50 pixels are ignored to filter out dust and noise.
  • Padding around the detected region: 2.5% of image size, clamped to 15–100 px.
  • DPI metadata from the source file is preserved in the output.

Tool 2 of 7

Straighten Images Beta (in Testing)

Deskews images without cropping them. Use this when images are already cropped to the right bounds but still need rotation correction. Original files are untouched; straightened copies go to a subfolder.

Input

A folder of image files. Supported: TIFF, JPEG, PNG, BMP, GIF.

Output

  • input_folder/straightened/ — deskewed image copies
  • input_folder/errored-files/straighten/ — run-level error folder

How to Use

  1. Select the image folder using the folder picker button.
  2. The stats strip shows how many supported image files were found.
  3. Click Start. The live log shows each file as it processes.
  4. When complete, open straightened/ to review output.

Notes

  • Uses a Hough Line Transform deskew pass to estimate page angle.
  • Output images keep the same pixel dimensions as their source files.
  • DPI metadata from the source file is preserved when available.

Tool 3 of 7

Merge TIFFs

Combines groups of TIFF page files into multi-page TIFFs. Files are grouped by their naming pattern — everything before the trailing numeric suffix is the group name. Mixed folders are supported: unrecognized files are skipped with a warning rather than stopping the job.

Input

A folder of TIFF files following the naming pattern:
{name}_{group}_{sequence}.tif or .tiff

Examples: 9200-T16-000_207_3.tif, 9200-T16-000_207_003.tif, 9200-T16-000_207_1000.tif

Output

  • input_folder/merged/ — one multi-page TIFF per group
  • input_folder/errored-files/ — files that failed

How to Use

  1. Select the TIFF folder using the folder picker.
  2. The tool scans the folder and displays the number of detected merge groups.
  3. Click Start. Each group produces one output TIFF.
  4. Review merged files in merged/ when complete.

Notes

  • The sequence is any positive integer, with or without leading zeros.
  • Pages within each group are sorted by numeric value before merging, so _10 comes after _9.
  • A one-file group is valid and produces a single-page multi-frame TIFF.
  • Unmatched TIFFs are skipped with a warning; they do not fail the job.
  • Output DPI is taken from the first valid file in each group.

Tool 4 of 7

Split Multi-Page TIFFs

Extracts each page of a multi-page TIFF into its own individual single-page TIFF. Useful when an archive receives multi-page masters that require page-level access. Single-page TIFFs are silently skipped — only multi-page files are split.

Input

One or more TIFF files, or a folder of TIFFs. The picker lets you choose between file mode and folder mode.

Output

  • Folder mode: selected_folder/extracted-pages/
  • File mode: {original_name}_pages/ alongside each source

How to Use

  1. Click the picker and choose Select Folder or Select Files.
  2. Selected files are scanned; the count excludes single-page TIFFs that will be skipped.
  3. Click Start. Pages are written to the output folder as extracted.
  4. Review extracted pages in the output folder when complete.

Notes

  • Single-page TIFFs are automatically skipped — no action needed.
  • Output page files are named {original_name}_page_{###}.tif.
  • DPI metadata from the source is preserved in each extracted page when available.

Tool 5 of 7

Add Border

Adds a white border around every image in a folder using the same proportional padding logic as Auto Crop. Intended for book scans, presentation-ready images, or any set that needs consistent margins. Original files are never modified.

Input

A folder of image files (TIFF, JPEG, PNG, BMP, GIF).

Output

  • input_folder/bordered/ — images with border added

How to Use

  1. Select the image folder using the folder picker.
  2. The file count shows how many images will be processed.
  3. Click Start. Bordered copies are written to bordered/.
  4. Original images remain untouched in the source folder.

Notes

  • Border width: 2.5% of the image's shorter dimension, clamped to 15–100 px.
  • Uses the same padding rule as Auto Crop for consistent pipeline output.
  • Border color is always white regardless of image content.

Tool 6 of 7

OCR to PDF

Groups scan image files by their trailing four-digit sequence number and produces one searchable PDF per group in a PDFs/ subfolder. A single valid file is still processed as a one-page PDF. Requires Tesseract OCR installed locally.

Input

A folder of scan images named:
{name}_{####}.ext

Example: packet_0001.tif, packet_0002.tif
Supported: TIFF, JPEG, PNG, BMP

Output

  • input_folder/PDFs/ — one searchable PDF per document group
  • input_folder/errored-files/ocr-pdf/ — files that failed

How to Use

  1. Select the image folder. The tool groups files and shows the document count.
  2. Choose options before starting:
    • Skip existing — skip groups that already have an output PDF.
    • Quality precheck — flag low-quality pages; they stay in the PDF but without OCR text.
    • Reduce PDF — apply compression to output PDFs; choose a compression profile.
  3. Click Start. Per-page and per-job progress bars update as work proceeds.
  4. PDFs appear in PDFs/ as each group completes.
  5. Use Save Log to export the run log after the job finishes.

Notes

  • Tesseract OCR must be installed with the English language pack (eng).
  • Multi-page TIFFs in the input are expanded to per-page entries before grouping.
  • The output PDF base name is everything before the trailing _####.
  • Quality precheck results are shown in the log; flagged pages are not discarded.
  • Compression profiles are shared with PDF Conversion for consistent output sizes.

Tool 7 of 7

PDF Conversion

Four operations in one panel: reduce PDF file size, split a PDF into pages, export PDF pages as images, and extract a selected page range into a new PDF. Select the operation first — the input picker and available options update accordingly.

Operations

Reduce Size

Compress PDFs

Input: a single PDF or a folder of PDFs.
Output: reduced-pdfs/ next to the source.
Choose a compression profile from the dropdown.

Split PDF

Split into Pages

Input: a single PDF file.
Output format: Single-page PDFs, JPEG, PNG, or TIFF images.
Output: split-pdfs/{pdf_name}/ or split-images/{pdf_name}/.

Extract Pages

Pull a Page Range

Input: a single PDF file. Enter page numbers or ranges (e.g. 1,3,5-8).
Output: extracted-pages/.
Optionally write a separate remaining-pages PDF. The source PDF is left unchanged.

PDF/A (Preview)

Convert to PDF/A

Input: a single PDF file.
Converts to archival PDF/A format. This feature is in preview — verify output in your PDF/A validator before relying on it.

How to Use

  1. Select an operation from the operation dropdown at the top of the panel.
  2. Use the picker to select a file or folder (the picker label updates per operation).
  3. Set any operation-specific options (compression profile, output format, page range).
  4. Click Start. The log shows progress file by file.
  5. Output appears in the subfolder next to the source when the job completes.

Notes

  • Reduce Size is the only operation that supports folder input; others require a single file.
  • Split and Extract use pypdfium2 for rendering — included in requirements.txt.
  • Page numbers in Extract are 1-based and can be individual values or ranges.
  • PDF operations copy outputs into folders and do not overwrite or delete the source PDF.

End to End

Typical Workflow

1. Scan or collect images

Start with a folder of raw scan outputs — TIFF, JPEG, or PNG.

2. Straighten Images (optional)

Deskew raw or already-cropped pages. Output lands in straightened/.

3. Auto Crop

Remove scanner-created white borders. Output lands in cropped/.

4. Add Border (optional)

Add consistent margins to the cropped images — useful for book scans or presentation sets.

5. Merge TIFFs

Combine correctly named page files into multi-page TIFFs. Ensure files follow {name}_{group}_{sequence}.tif before running.

6. Split TIFFs (if needed)

Break apart any existing multi-page TIFFs that need page-level access.

7. OCR to PDF

Build searchable grouped PDFs from a folder of {name}_{####} page images. Enable quality precheck and PDF compression for production use.

8. PDF Conversion (as needed)

Reduce file size, split pages for delivery, export page images, or extract specific page ranges from finished PDFs.

Setup

Requirements

Source Checkout Packages

  • Pillow >= 10.0.0
  • opencv-python >= 4.8.0
  • numpy >= 1.24.0
  • pypdf >= 5.0.0
  • pypdfium2 >= 4.30.0
  • flask >= 3.0.0
  • pywebview >= 4.4.0

Install: pip install -r requirements.txt

External Tools

  • Tesseract OCR — required for OCR to PDF only
  • English language pack (eng) must be installed
  • All other tools work without Tesseract

The app shows dependency status where a tool needs external OCR or PDF conversion support.

Windows EXE Deployment

The supported release artifact is DPA Image Toolkit.exe. Download it, then launch the EXE directly.

Settings and theme preferences are stored in the current user's app data folder, so the EXE can run from locked-down folders without admin write access. The deploy/ folder contains EXE release notes only; the old source-copy bundle has been retired.
