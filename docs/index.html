Included Tools

7 tools
✂
Auto Crop
Detects and crops scanner-created white space. Optional straightening can run before crop analysis.
In: image folder  ·  Out: cropped/
↻
Straighten Images
Deskews already-cropped or raw image folders without changing their crop canvas.
In: image folder  ·  Out: straightened/
⊞
Merge TIFFs
Combines {name}_{group}_{sequence}.tif page files into multi-page TIFFs by group.
In: TIFF folder  ·  Out: merged/
⇵
Split TIFFs
Extracts each page of a multi-page TIFF into individual single-page files. Single-page TIFFs are skipped.
In: TIFF files or folder  ·  Out: extracted-pages/
▣
Add Border
Adds a white border to every image using the same 2.5% padding rule as Auto Crop.
In: image folder  ·  Out: bordered/
⎘
OCR to PDF
Groups {name}_{####} scan images into searchable PDFs via Tesseract OCR. Quality precheck optional.
In: image folder  ·  Out: PDFs/
▤
PDF Conversion
Four operations: reduce size, split pages, export page images, extract page ranges.
In: PDF file or folder  ·  Out: operation-dependent
