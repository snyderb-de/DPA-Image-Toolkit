T-004
Auto Crop: batch preview mode
Preview detected crop regions for all files before committing the full batch. Requires a preview rendering pass using OpenCV contour results.
T-005
TIFF Merge: per-page DPI preservation
Current behavior takes DPI from the first valid file in the group. Each page should carry its source DPI into the merged output.
T-006
TIFF Merge: advanced compression options
Add JPEG, LZW, and PackBits compression to merge output. Currently writes uncompressed or default TIFF compression only.
T-007
TIFF Merge: memory-safe streaming for large batches
Batches of 200+ pages can exhaust memory. Need a streaming approach that writes pages incrementally rather than loading all frames at once.
T-008
OCR: tune messy-scan heuristic against production samples
Quality precheck thresholds need calibration against real workflow scans. Lab test set may not reflect actual microfilm or archival scan quality.
T-009
OCR: manual override for quality-flagged pages
Let users override the quality gate on a per-page basis. Currently flagged pages are handled automatically with no user control after the fact.
T-010
Undo support
Move output back and restore originals for a completed job. Output always goes to a subfolder currently so no data is at risk — purely a convenience workflow.
T-011
Decide code-signing/distribution policy
The current EXE is unsigned. That is acceptable for controlled rollout, but broader distribution may need Authenticode signing to reduce Windows SmartScreen friction.

Included Tools

7 tools
✂
Auto Crop
Detects and crops scanner-created white space. Optional straightening can run before crop analysis.
In: image folder  ·  Out: cropped/
↻
Straighten Images Beta (in Testing)
Deskews already-cropped or raw image folders without changing their crop canvas.
In: image folder  ·  Out: straightened/
⊞
Merge TIFFs
Combines {name}_{group}_{sequence}.tif page files into multi-page TIFFs by group.
In: TIFF folder  ·  Out: merged/
⇵
Split TIFFs
Extracts each page of a multi-page TIFF into individual single-page files. Single-page TIFFs are skipped.
In: TIFF files or folder  ·  Out: extracted-pages/
▣
Add Border
Adds a white border to every image using the same 2.5% padding rule as Auto Crop.
In: image folder  ·  Out: bordered/
⎘
OCR to PDF
Groups {name}_{####} scan images into searchable PDFs via Tesseract OCR. Quality precheck optional.
In: image folder  ·  Out: PDFs/
🗎
PDF Conversion
Four operations: reduce size, split pages, export page images, extract page ranges.
In: PDF file or folder  ·  Out: operation-dependent
